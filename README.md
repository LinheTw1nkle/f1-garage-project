# F1 Garage

An interactive Formula 1 garage and data archive, created as a personal web design assignment.

## Features

- Interactive 3D car, aerodynamics and database modules.
- Circuit explorer, driver and team profiles, race results and tyre strategy visualizations.
- SF26 outline loading screen with resource preloading.
- Desktop and mobile layouts, with reduced-motion support.

## Run

Open `index.html` in a recent browser with WebGL 2 support, or serve this directory with a static web server. The project does not require a build step.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select **main / (root)**. Keep the directory structure intact: `index.html`, `css/`, `js/`, `fonts/` and `img/` are all required.
